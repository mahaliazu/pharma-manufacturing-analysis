# pharma-manufacturing-analysis
Data analysis project using SQL and Tableau to analyze pharmaceutical manufacturing performance.

## Project Overview
This project analyzes pharmaceutical manufacturing data to evaluate production performance, product quality, and operational efficiency. The analysis focuses on production target achievement, defect rates, production shortfalls, and machine downtime.

## Tools
- SQL (Google BigQuery)
- Tableau

## Dataset
The dataset consists of 600 rows and 16 columns, containing pharmaceutical manufacturing production data.

The dataset was synthetically generated for portfolio and analytical practice purposes.

## Analysis
The project includes 14 analyses:
1. Executive Summary KPI
2. Product Performance
3. Monthly Production Trend
4. Production Target Shortfall
5. Production Line Performance
6. Defect Rate by Product Category
7. Quality Status Analysis
8. Downtime Analysis
9. Cost per Good Unit
10. Energy Intensity
11. Product Achievement Ranking
12. Month-over-Month Production Change
13. Batch Review Flags
14. Quarterly Performance Summary

## Dashboard
The interactive dashboard was created using Tableau to visualize the results of the analysis.

## Key Findings
- Overall production target achievement reached 95.62%.
- The overall defect rate was 2.20%.
- Total production shortfall reached 341,825 units.
- Production Line C recorded the highest defect rate at 3.04%, compared to Line A (1.81%) and Line B (1.78%).
- Batches with Review status showed a defect rate of 4.07%.
- High downtime records had an average downtime of 3.31 hours and a production target achievement of 90.72%.
